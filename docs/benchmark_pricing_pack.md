## Рекомендации для Agent 2

### Валидация цен

- Проверять `price_min <= price_max`
- Все цены в RUB
- Обновлять `verified_date` при перепроверке

### Для калькулятора

- Использовать диапазоны (min-max), не точные значения
- Показывать дисклеймер под расчётом
- Добавлять коэффициент сложности (1.0-2.0)

### Для UI

- Форматировать: "от 350 ₽/м²" или "350-600 ₽/м²"
- Для комплексных: "по запросу"
- Для ТО: указывать период (₽/мес)
