## Общие паттерны для всех разделов

### Hero блок (единый стандарт)

- Заголовок: название услуги
- Подзаголовок: ценность + тип объектов
- 3 trust-фактора (лицензия/срок/география)
- 1 основной CTA: "Заказать аудит объекта"

### Stats Cards (4 метрики)

- Лет на рынке / опыта
- Объектов сдано
- Сертификация (ISO, СРО, МЧС)
- Поддержка (24/7, SLA)

### Кейсы (структура)

- Название объекта
- Тип / локация
- Площадь
- Срок реализации
- Бюджет (диапазон)
- Что сделано (список)

### FAQ (8-12 вопросов)

- Процесс работы
- Цены / смета
- Сроки
- Документы / лицензии
- Гарантия
- Интеграции
- ТО / поддержка

### SEO блок

- Текст 2000-3000 знаков
- Ключевые слова по разделу
- Внутренние ссылки
- Микроразметка (Service, FAQPage)
