## Валидация (правила для Agent 2)

### Обязательные проверки

1. У каждого `service_slug` есть:
   - Минимум 1 hero offer
   - Минимум 3 stats cards
   - Минимум 3 solution kits
   - Минимум 10 catalog items
   - Минимум 5 process steps
   - Минимум 8 faq items

2. Ценовые диапазоны:
   - `price_min` >= 0
   - `price_max` >= `price_min` (если оба указаны)
   - `price_type` = "range" → оба `price_min` и `price_max` обязательны

3. Ссылочная целостность:
   - Все `service_slug` существуют в листе `services`
   - Все `parent_item_id` существуют в `catalog_items`
   - Все `benchmark_source_ids` существуют в `price_benchmarks`

4. Единицы измерения:
   - Все `unit` значения существуют в `glossary_units`

## Контракт для импорта (Agent 2)

### Формат файла

- `.xlsx` или `.csv` (множественные файлы)
- Кодировка: UTF-8
- Разделитель: запятая (для CSV)

### Скрипт импорта

```bash
pnpm import-services-xlsx --input ./docs/Security_Integrator_CRM_Model_Advanced.xlsx --output ./src/generated/
```

### Выходные файлы

- `src/generated/services-content.json` — все данные
- `src/generated/services-index.ts` — список slug
- `src/generated/content-meta.json` — метаданные

### Dry-run режим

```bash
pnpm import-services-xlsx --input ./file.xlsx --dry-run
```

## Рекомендации по заполнению

### Для контент-менеджеров

1. Не редактировать generated файлы вручную
2. Использовать только UTF-8 кодировку
3. Проверять даты в `verified_date` для benchmark цен
4. Заполнять `notes` для внутренних комментариев
5. Менять `is_active` = FALSE вместо удаления строк

### Для редакторов

1. Hero заголовки: максимум 60 символов
2. Subhead: максимум 140 символов
3. FAQ вопросы: максимум 100 символов
4. Catalog item names: максимум 80 символов
