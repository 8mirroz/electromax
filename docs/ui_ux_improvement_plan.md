## 🔴 Приоритет P0 — Критические проблемы

### 1. Value Proposition в Hero (5 секунд на понимание)

**Проблема:** Текущий заголовок "Интеграция систем безопасности" слишком общий. Пользователь не сразу понимает **для кого** и **какую проблему** решает компания.

**Решение по StoryBrand:**

```
Было: "Интеграция систем безопасности — надежная | умная | быстрая"
Стало: "Комплексные системы безопасности для заводов и складов под ключ.
        Лицензия МЧС. Гарантия прохождения проверок."
```

**Почему:** Показываем:

- **Кто мы** (интегратор)
- **Для кого** (заводы, склады — не "все")
- **Результат** (пройдёт проверку МЧС)

**Фреймворк:** [StoryBrand](https://storybrand.com) — клиент герой, вы проводник

---

### 2. Социальное доказательство выше сгиба

**Проблема:** Нет доверия в первом экране. B2B клиенты ищут подтверждение надёжности.

**Решение (добавить в Hero):**

```tsx
<div className="flex items-center gap-8 mt-12 text-muted-foreground">
  <div className="flex items-center gap-2">
    <ShieldCheck className="w-5 h-5 text-primary" />
    <span className="text-sm font-medium">500+ объектов</span>
  </div>
  <div className="flex items-center gap-2">
    <Award className="w-5 h-5 text-primary" />
    <span className="text-sm font-medium">Лицензия МЧС №12345</span>
  </div>
  <div className="flex items-center gap-2">
    <Clock className="w-5 h-5 text-primary" />
    <span className="text-sm font-medium">12 лет на рынке</span>
  </div>
</div>
```

**Исследование:** Baymard — 73% пользователей оценивают доверие в первые 10 секунд

---

### 3. CTA с конкретным действием

**Проблема:** "Заказать проект" — размыто. Неясно что будет дальше.

**Решение:**
| Было | Стало |
|------|-------|
| Заказать проект | **Рассчитать стоимость** |
| Все услуги | **Получить консультацию** |

**Добавить микро-копирайт под CTA:**

```
✓ Бесплатный выезд инженера
✓ Смета в течение 24 часов
✓ Никаких скрытых платежей
```

**Фреймворк:** [Fitts's Law](https://lawsofux.com/fittss-law) — CTA должен быть лёгкой мишенью

## 🟡 Приоритет P1 — Важные улучшения

### 4. Карточки услуг — добавить иерархию цен

**Проблема:** Цены "от 450 ₽/м²" не говорят о полном бюджете. B2B клиент хочет понимать порядок цифр.

**Решение (добавить в карточку):**

```tsx
<div className="space-y-4">
  <p className="text-sm text-muted-foreground">
    Типовой объект 500 м²: <span className="font-bold text-foreground">~225 000 ₽</span>
  </p>
  <div className="flex gap-2 flex-wrap">
    <span className="px-2 py-1 bg-primary/10 text-primary text-xs font-bold rounded">3-5 дней</span>
    <span className="px-2 py-1 bg-primary/10 text-primary text-xs font-bold rounded">
      Гарантия 3 года
    </span>
  </div>
</div>
```

**Исследование:** NN/g — прозрачность ценообразования повышает конверсию на 28%

---

### 5. Секция "Проблемы → Решение" перед услугами

**Проблема:** Пользователь может не узнать свою ситуацию в списке услуг.

**Решение (вставить перед карточками):**

```
┌─────────────────────────────────────────────────────────┐
│  Сталкиваетесь с этими проблемами?                      │
├─────────────────────────────────────────────────────────┤
│  ⚠️ Предписание от инспектора МЧС                       │
│  ⚠️ Не проходит приёмка объекта                         │
│  ⚠️ Старая система не работает                          │
│  ⚠️ Нужна модернизация без остановки производства       │
└─────────────────────────────────────────────────────────┘
           ↓
┌─────────────────────────────────────────────────────────┐
│  Мы решаем эти задачи за 5 шагов:                       │
│  1. Аудит → 2. Проект → 3. Монтаж → 4. Наладка → 5. Сдача │
└─────────────────────────────────────────────────────────┘
```

**Фреймворк:** [Problem-Agitation-Solution](https://storybrand.com)

### 6. Кейсы с цифрами, а не картинки

**Проблема:** "Комплексная система безопасности класса А" — ничего не говорит.

**Решение (переписать карточки):**

```
┌────────────────────────────────────────────┐
│  [Фото объекта]                            │
│                                            │
│  🏢 Бизнес-центр "Вегас", 45 000 м²        │
│  ─────────────────────────────────────     │
│  ✓ 1200 камер с распознаванием лиц         │
│  ✓ СКУД на 5000 сотрудников                │
│  ✓ Срок: 4 месяца                          │
│  ✓ Бюджет: 12.5 млн ₽                      │
│  ✓ Сдано с первого раза                    │
│                                            │
│  [Читать кейс →]                           │
└────────────────────────────────────────────┘
```

**Исследование:** Baymard — конкретные цифры повышают доверие на 67%

### 7. Липкая шапка с телефоном

**Проблема:** В текущей навигации нет телефона. B2B клиенты часто хотят позвонить сразу.

**Решение:**

```tsx
<nav className="sticky top-0 z-50 ...">
  <div className="flex items-center gap-6">
    {/* Лого */}
    {/* Меню */}
    <div className="flex items-center gap-4 ml-auto">
      <a href="tel:+74951234567" className="font-bold text-foreground hover:text-primary">
        +7 (495) 123-45-67
      </a>
      <Button>Заказать звонок</Button>
    </div>
  </div>
</nav>
```

## 🟢 Приоритет P2 — Улучшения опыта

### 8. Квиз "Рассчитать стоимость за 1 минуту"

**Проблема:** Пользователь не готов оставить заявку сразу.

**Решение:** Интерактивный калькулятор с 4 шагами:

```
1. Тип объекта: [Офис] [Склад] [Производство]
2. Площадь: [____] м²
3. Что нужно: ☑ АПС ☑ СКУД ☑ Видеонаблюдение
4. Контакты: [Телефон] → Получить расчёт
```

**Почему:** Micro-commitment — маленькое действие ведёт к большому

---

### 9. Страница услуги по структуре лендинга

**Проблема:** Страницы услуг могут не следовать проверенной структуре.

**Структура по Baymard (11 блоков):**

```
1. Hero с заголовком-результатом
2. Калькулятор стоимости
3. Что входит (список работ)
4. Оборудование (бренды с лого)
5. Процесс работы (таймлайн)
6. Примеры работ (фото до/после)
7. Лицензии и сертификаты
8. Отзывы (сканы благодарностей)
9. FAQ (5-7 вопросов)
10. Гарантия и обслуживание
11. CTA с формой
```

---

### 10. Форма с прогрессом и валидацией

**Проблема:** Длинные формы пугают.

**Решение:**

```tsx
<Stepper steps={['Контакты', 'Объект', 'Детали']} current={1} />

✓ Валидация в реальном времени
✓ Маска телефона: +7 (___) ___-__-__
✓ Подсказки у полей
✓ Кнопка "Отправить" активна только при валидных данных
```

**Исследование:** Baymard — 22% пользователей бросают форму из-за ошибок валидации

---

### 11. Чат/мессенджер в углу

**Проблема:** Не все хотят звонить или оставлять заявку.

**Решение:**

```tsx
<FloatingButton className="bottom-6 right-6">
  <TelegramIcon /> Написать в Telegram
</FloatingButton>
```

**Почему:** В РФ Telegram — предпочтительный канал для B2B

---

### 12. Мобильная адаптация CTA

**Проблема:** На мобильных CTA могут быть слишком мелкими.

**Решение (Tailwind):**

```tsx
<Button
  className="w-full sm:w-auto h-14 text-base font-bold"
  // Минимум 44x44px по Apple HIG
/>
```

**Стандарт:** [Apple HIG](https://developer.apple.com/design/human-interface-guidelines) — мин. 44x44px для тач-целей
